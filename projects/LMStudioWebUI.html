LMStudioWebUI

A browser-based chat interface for interacting with your LM Studio server from any device.

The Idea

LMStudioWebUI is a web-based chat client that connects to your locally hosted LM Studio server. It lets you chat with your local AI models from any device on your network — including phones and tablets — without needing the LM Studio desktop app installed on each device.

The app uses no backend server. All communication is direct between your browser and the LM Studio server, keeping everything local and private.

Features

  • Dark mode interface with purple theme
  • Connect to any LM Studio server (custom address and port)
  • LaTeX math rendering via MathJax
  • Markdown rendering with syntax-highlighted code blocks (Highlight.js)
  • Mobile-friendly design
  • Multiple chat sessions with IndexedDB persistence
  • Vision model support with image upload
  • Model selection dropdown
  • Export chats as HTML or Markdown
  • Debug console via ?debug URL parameter

How It Works

The app is a static website — just HTML, CSS, and JavaScript. No build step, no backend. You start LM Studio in server mode, point the web UI at your server address, and start chatting.

Chat history is persisted in the browser using IndexedDB, so your conversations survive page refreshes. You can export any chat as HTML or Markdown for offline reference.

Tech Stack

  • Vanilla JavaScript — no framework dependencies
  • IndexedDB — client-side chat persistence
  • MathJax — LaTeX math rendering
  • Highlight.js — code syntax highlighting
  • Marked.js — Markdown rendering
  • Eruda — mobile debug console
  • GitHub Pages — zero-setup deployment
