Merbs

A lightweight, customizable portfolio site built for GitHub Pages.

The Idea

Merbs is a portfolio website designed to be hosted on GitHub Pages with zero build step. It uses vanilla HTML, CSS, and JavaScript for fast, simple deployment. The entire site is driven by a single projects.json configuration file that defines your project cards, and individual HTML template files for each project's detail page.

The goal is a fast, minimal portfolio that showcases your work without the overhead of a framework or build pipeline. Clone it, drop in your projects, and deploy.

Features

  • Zero build step — just HTML, CSS, and vanilla JavaScript
  • Project cards driven by a single projects.json config file
  • Per-project HTML templates loaded in a modal on click
  • GitHub contribution graph visualization
  • Three.js animated background
  • Dark theme with purple accent colors
  • Mobile-friendly responsive design
  • Markdown rendering via Marked.js for project content
  • Hosted directly on GitHub Pages

How It Works

Edit projects/projects.json to add, remove, or reorder project cards. Each project entry specifies a title, description, image, link, GitHub URL, and an associated HTML template file in the projects/ directory.

When a visitor clicks a project card, the site loads the corresponding HTML template into a modal overlay, displaying the full project details without leaving the page.

Tech Stack

  • Vanilla JavaScript — no framework dependencies
  • CSS — custom dark theme styling
  • Three.js — animated background visualization
  • Marked.js — Markdown rendering
  • GitHub API — contribution graph data
  • GitHub Pages — zero-setup deployment
